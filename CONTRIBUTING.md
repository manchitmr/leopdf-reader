# Contributing to LeoPDF Reader

Thanks for helping! LeoPDF is in its early stages, so the most useful contributions right now are:

1. **Sample PDFs** — Sinhala, Tamil, or mixed-language PDFs that break in other readers. Legacy-font PDFs (FM Abhaya, Bamini, etc.) and scanned documents are especially valuable. Only share documents you have the right to share, with no personal data.
2. **Legacy font info** — names of legacy fonts you see in real documents, and their character mappings if known.
3. **Translations** — UI strings in සිංහල and தமிழ்.
4. **Design feedback** — comment on the [design spec](docs/superpowers/specs/2026-09-27-leopdf-design.md) via issues.
5. **Code** — once the v0.1 implementation plan lands, issues labelled `good first issue` will be the place to start.

## How to contribute

- Open an issue before large changes so we can agree on the approach.
- Fork, create a branch, and open a pull request against `main`.
- Keep pull requests focused on one change.
- Add tests for new behaviour. Sinhala/Tamil text handling changes must include test cases.
